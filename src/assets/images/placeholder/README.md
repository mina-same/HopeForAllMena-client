## 🎯 **Image Requirements**

### **Technical Specifications**
- **Format**: JPG or PNG
- **Quality**: High resolution (at least 72 DPI for web)
- **File Size**: Optimize for web (under 500KB each)
- **Dimensions**: As specified above

### **Content Guidelines**
- **Professional**: Clean, ministry-appropriate
- **Diverse**: Show different ages, ethnicities, backgrounds
- **Authentic**: Real ministry situations, not overly staged
- **Inspiring**: Positive, uplifting, faith-focused
- **Relevant**: Directly related to the section content

### **Style Guidelines**
- **Color Scheme**: Warm, welcoming tones
- **Lighting**: Natural, bright, inviting
- **Composition**: Professional, well-framed
- **Mood**: Positive, encouraging, hopeful

## 💡 **Pro Tips**

- **Consistency**: Use similar lighting and style across all images
- **Quality**: Higher resolution images look better on all devices
- **Optimization**: Compress images for faster loading
- **Backup**: Keep original high-res versions
- **Alt Text**: The code already includes descriptive alt text

## 🔧 **Troubleshooting**

If images don't display:
1. Check file names match exactly
2. Verify file extensions (.jpg vs .jpeg)
3. Ensure files are in the correct directory
4. Check file permissions
5. Clear browser cache
